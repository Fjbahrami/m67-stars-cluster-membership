# Dataset Documentation

## Dataset Name
M67 Gaia DR3 Initial Sample

## Source
ESA Gaia Data Release 3

## Table
gaiadr3.gaia_source

## Target Object
Messier 67 (M67)

## Query Center
- RA: 132.825 degrees
- DEC: 11.800 degrees

## Search Radius
0.5 degrees

## Initial Filtering
- G magnitude < 20
- Parallax available
- PMRA available
- PMDEC available

## Selected Features
- RA
- DEC
- Parallax
- PMRA
- PMDEC
- BP-RP
- G magnitude
- Astrometric quality indicators

## Purpose
The dataset is intended for exploratory analysis and unsupervised clustering to investigate probable M67 cluster members.

## Notes
No membership labels are assigned during initial data extraction.
